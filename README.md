# Instagram Audit 360

Агент, який розбирає твій Instagram і каже, що робити в понеділок.

Не дашборд із красивими цифрами — звіт, у якому кожен блок закінчується дією,
цифрою «звідки → куди» і прикладом акаунта, у якого це вже працює.

Раз на тиждень він робить це сам і надсилає підсумок у Telegram.

---

## Що всередині звіту

**Ритм.** Скільки охоплення з'їдають пости, які вийшли надто щільно. Зазвичай це
найбільший важіль в акаунті — і виправляється календарем, а не новим контентом.

**Що залетіло, що ні.** Реальні кадри твоїх постів у двох рядах із цифрами.
Різницю між ними видно очима, а не в таблиці.

**Сітка профілю.** Дев'ять крайніх постів так, як їх бачить людина, що прийшла
з рілса, з охопленням на кожній плитці.

**Де ти відносно ніші.** Перегляди рілса до бази підписників — у тебе й у колег.
Без цієї цифри неможливо сказати, 20% — це мало чи нормально.

**Ціна підписника.** Скільки охоплення потрібно на одну підписку і який крок вужчий:
до профілю не доходять чи профіль не продає. *(потрібна Meta)*

**Що обмежує охоплення.** Кореляційна карта: що йде разом з охопленням, а що дає нуль
і не варте уваги. *(потрібна Meta)*

## Встановлення

```
/plugin marketplace add vitalii-matvieiev/agent-ista-audit-360
/plugin install ig-audit-360@matvieiev
```

Далі одна команда — і агент усе зробить сам:

```
/ig-audit-setup
```

Він спитає про акаунт і конкурентів, **сам відкриє браузер**, проведе через
реєстрацію ключа, створить Telegram-бота і перевірить, що все живе.
Термінал відкривати не треба, JSON редагувати не треба.

Потім:

```
/ig-audit            — прогнати аудит
/ig-audit-weekly     — поставити щотижневий звіт
```

**Потрібно:** Python 3.8+ і безкоштовний ключ [ScrapeCreators](https://scrapecreators.com).
Не обов'язково, але сильно краще: `pip install pillow` — стискає кадри у звіті.

## Два рівні

| | Рівень 1 · 5 хвилин | Рівень 2 · +30 хвилин |
|---|---|---|
| Потрібно | ключ ScrapeCreators | + застосунок Meta і бізнес-акаунт |
| Темп, паузи, ER | ✅ | ✅ |
| Перегляди рілсів | ✅ | ✅ |
| Канібалізація ритму | ✅ | ✅ |
| Порівняння з колегами | ✅ | ✅ |
| Топ і дно постів із кадрами | ✅ | ✅ |
| Охоплення, збереження, шери | — | ✅ |
| Утримання рілса | — | ✅ |
| Воронка й ціна підписника | — | ✅ |
| Кореляційна карта | — | ✅ |

Починай з рівня 1 — він працює для будь-якого акаунта і вже дає звіт.
Meta підключиш, коли захочеш: `/ig-audit-setup meta`.

**Чого немає навіть на рівні 2.** Meta не віддає підписки й переходи в профіль
для рілсів у принципі. Тапи в сторіс живуть 24 години. Утримання по секундах API
не дає — тільки середній час. Агент про це чесно пише в розділі «Чого немає»
і ніколи не видає відсутню метрику за нуль.

## Приватність

Ключі лежать у `~/.ig-audit/config.json` з правами `600` — поза репозиторієм,
на твоїй машині. Нікуди не відправляються, крім самих Meta й ScrapeCreators.
Дані акаунта нікуди не вивантажуються: збір, розрахунок і звіт — усе локально.
