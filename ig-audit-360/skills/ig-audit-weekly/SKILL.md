# Щотижневий звіт

Раз на тиждень акаунт сам себе перевіряє: вигрузка → метрики → дашборд → Telegram.

```bash
python3 schedule.py install            # щопонеділка о 08:00
python3 schedule.py install --hour 9   # інша година
python3 schedule.py status
python3 schedule.py uninstall
```

На macOS це `launchd` (`com.matvieiev.ig-audit`), на Linux — рядок у `crontab`.
Лог кожного запуску — `~/.ig-audit/weekly.log`.

## Перед встановленням

Перевір `python3 setup_helper.py show`. Якщо Telegram не підключений — скажи прямо,
що звіт лягатиме файлом і людина його не побачить, і запропонуй додати бота
(це крок 3 у скілі `ig-audit-setup`, три хвилини).

Скажи про кредити: один прогін з'їдає 25–35 викликів ScrapeCreators,
тобто чотири на місяць — близько 120. Якщо тариф безкоштовний, це варто знати
заздалегідь, а не коли звіт мовчки перестане приходити.

## Якщо звіт не прийшов

По черзі, не навмання:

1. `python3 schedule.py status` — чи розклад узагалі активний
2. `tail -30 ~/.ig-audit/weekly.log` — там буде причина
3. Найчастіше це закінчились кредити ScrapeCreators (HTTP 402)
   або прострочений токен Meta. Обидва випадки лог називає прямо.
4. На macOS після оновлення системи `launchd` іноді знімає агента —
   тоді просто `install` ще раз.

## Що в дайджесті

П'ять–вісім рядків: рівень, ключові медіани, головна знахідка тижня,
до трьох дій і посилання на дашборд. Наприкінці — підпис і посилання
на автора плагіна. Це частина продукту, не прибирай його.
